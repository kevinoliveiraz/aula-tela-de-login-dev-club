# Tela de login do Club

Projeto desenvolvido durante uma aula de criação de tela de login, utilizando HTML e CSS. Neste exercício, aprendi a estruturar um formulário e estilizar seus elementos.

## O que aprendi

- Usar a tag `<main>` para organizar o conteúdo principal da página.
- Criar o formulário com a tag `<form>`.
- Utilizar `<h1>` para o título principal.
- Criar campos de e-mail e senha com a tag `<input>`.
- Usar `<div>` para agrupar elementos e criar as caixas do layout.
- Criar o botão de login com a tag `<button>`.
- Utilizar os tipos `email`, `password` e `checkbox` nos campos do formulário.
- Adicionar ícones da biblioteca Boxicons por meio de um link no HTML.
- Aplicar efeitos com `:hover` quando o ponteiro do mouse passa sobre um elemento.
- Adicionar fontes externas e aplicá-las ao estilo da página.

## Biblioteca de ícones

Para utilizar os ícones do Boxicons, adicionei este link ao HTML:

```html
<link href="https://unpkg.com/boxicons@2.1.4/css/boxicons.min.css" rel="stylesheet">
```
